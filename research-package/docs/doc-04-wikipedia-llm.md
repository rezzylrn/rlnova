# Model Bahasa Besar (excerpt Wikipedia EN)

## Definisi (lead Wikipedia)

A large language model (LLM) is a type of machine learning model designed
for natural language processing tasks such as language generation. LLMs
are language models with many parameters, and are trained with
self-supervised learning on a vast amount of text.

The term large language model refers to language models containing many
parameters. The most capable LLMs are trained on large datasets.

## Era 2020s (excerpt bagian "2020s")

In 2020, the introduction of GPT-3, a model with 175 billion parameters,
marked a significant milestone. The model was able to perform tasks it was
not explicitly trained for, a phenomenon known as few-shot learning. This
era saw the emergence of much larger models and demonstrated that scale
alone could improve capabilities.

In 2022, ChatGPT, which was based on OpenAI's GPT-3.5, was released and
became the fastest-growing consumer software application in history,
bringing large language models to widespread public attention. Modern
LLMs are typically trained with a combination of large-scale pretraining
on text corpora and subsequent fine-tuning, including reinforcement
learning from human feedback (RLHF), which aligns model outputs with
human preferences.

Instruction tuning, in which models are fine-tuned on examples of tasks
expressed as instructions, further improved the usability of these models
for end users.
